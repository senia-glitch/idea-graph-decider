# Решатель

Отвечает на вопросы пакетов вместо человека, когда включена автоматика. Обычный вопрос решает один
решатель; важный — два вслепую, при расхождении спорят, а если не сошлись — берётся решение,
которое дешевле отменить.

`skill.md` — порядок критического рассуждения; `__init__.py` — порядок работы пары (`resolve`).
Какие агенты и модели стоят за двумя решателями, задаётся в настройках оболочки.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
